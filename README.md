# AI Data Engineering Internship

This repository records small Python exercises completed during the internship work on the `April_17` branch.

## What I worked on

### `std_grade_calculator.py`
A simple grade calculator that:
- asks for full marks and obtained marks
- calculates the percentage
- prints a grade based on the percentage range

### `mulplication-table_generator.py`
A multiplication table generator that:
- asks for a number
- prints the multiplication table from 1 to 10

## How to run

Run either script with Python:

```bash
python std_grade_calculator.py
python mulplication-table_generator.py
```

## Branch record

- `main`: baseline branch
- `April_17`: branch used to add the grade calculator and multiplication table exercises
